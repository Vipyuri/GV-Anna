# Лендинг консультанта по грудному вскармливанию

Сайт-воронка для записи на консультации по ГВ (онлайн + выезд на дом).
Собран по ТЗ `ТЗ_лендинг_ГВ.docx` (десктоп-папка «ГВ»), итерация 1 — «скелет с реальными текстами».
Подробная документация проекта: [docs/DOCUMENTATION.md](docs/DOCUMENTATION.md).

Репозиторий: https://github.com/Vipyuri/GV-Anna · публикация: https://vipyuri.github.io/GV-Anna/

Стек: статические HTML + CSS + JS без фреймворков (по разделу 2 ТЗ).
Палитра: молочно-белый фон, бежевые секции, пыльно-розовый акцент, тёмно-серый текст, шрифт Inter/system-ui.

## Чек-лист перед публикацией (плейсхолдеры)

Всё, что в квадратных скобках `[...]` или с пометкой `TODO` в коде:

1. **Имя и цифры** — [Имя Фамилия], стаж, кол-во детей, часы обучения по лактации: шапка, hero, блок «Обо мне», футер, JSON-LD в `<head>`.
2. **Телефон** — заменить `+7 900 000-00-00` и `tel:+79000000000`, `wa.me/79000000000` в шапке, hero, форме, футере.
3. **Ссылки мессенджеров** — `t.me/username` → реальный ник (шапка, hero, бесплатная линия, блок мессенджеров, футер).
4. **Фото** — `img/photo-hero.svg` → живое фото в WebP (~800×1000). Стики «не сток» — по ТЗ.
5. **Сканы дипломов** — `img/diplom-1..4.svg` → реальные сканы в WebP (~800×600), при необходимости добавить 5–6-й `<figure>` в блок `#diplomy`.
6. **Отзывы** — блок `#otzyvy`: сейчас заглушки. Заменить на реальные (формат: «Мария, мама Мирона, 2 месяца»). Сразу после первых консультаций.
7. **Ссылка на бесплатный чат** — среда 19:00–20:00, блок «Как проходит».
8. **Реквизиты** — ИНН самозанятой в футере и политике; дата в политике; e-mail.
9. **Домен** — `ivanova-gv.ru` в `<link rel=canonical>`, JSON-LD, `robots.txt`, `sitemap.xml`.

## Подключить форму (отправка заявок в Telegram)

1. В Telegram создайте бота: @BotFather → `/newbot` → скопируйте токен.
2. Узнайте свой chat_id: напишите боту @userinfobot (или своему новому боту любое сообщение и откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates`).
3. Впишите оба значения в начало `js/main.js`:

```js
const CONFIG = {
  telegramBotToken: '123456:ABC-DEF...', // токен от BotFather
  telegramChatId: '123456789',           // ваш chat_id
  ...
};
```

До заполнения форма при отправке честно просит написать напрямую в Telegram — сайт можно публиковать сразу.

## Подключить Яндекс Метрику

1. Создайте счётчик на metrika.yandex.ru (включите вебвизор).
2. Впишите номер в `CONFIG.metricaId` в `js/main.js` — скрипт подгрузится сам.
3. Цели уже заведены: `form_submit` (отправка формы), `messenger_click` (клик по кнопкам мессенджеров) — создайте их в интерфейсе Метрики с такими же идентификаторами.

## Публикация

Вариант А — российский shared-хостинг (Timeweb, REG.ru; по ТЗ 40–300 ₽/мес):
1. Купить домен (ivanova-gv.ru или похожий).
2. Создать сайт, загрузить содержимое папки `gv-landing/` по FTP/файл-менеджеру в корень.
3. Включить бесплатный SSL Let's Encrypt в панели хостинга.

Вариант Б — GitHub Pages (репозиторий Vipyuri/GV-Anna): репозиторий уже создан, отправка — по deploy-ключу (см. документацию, раздел «Развёртывание»). Затем Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)` → Save. Адрес: https://vipyuri.github.io/GV-Anna/

После публикации:
- добавить сайт в Яндекс Вебмастер и Bing Webmaster, отправить sitemap.xml;
- проверить микроразметку валидатором Яндекса;
- прогнать PageSpeed Insights (цель: мобильный ≥ 90);
- создать карточку в Яндекс Бизнесе.
