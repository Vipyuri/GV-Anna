## 1. О проекте

**Назначение.** Одностраничный сайт-воронка для записи на консультации по грудному вскармливанию: онлайн (из любого города) и с выездом на дом (Гатчина, Ломоносовский район, юг Ленинградской области, Санкт-Петербург).

**Аудитория.** Беременные и кормящие мамы 24–40 лет, мобильный трафик из ВК / Telegram / поиска (по исследованию — 70 %+ заходов со смартфона).

**Цель версии 1** (по разделу 1 ТЗ): скорость и локальное SEO. Сайт открывается мгновенно на медленном мобильном интернете и собирает заявки через форму и мессенджеры. В версию сознательно НЕ вошли: блог, корзина, онлайн-оплата, личный кабинет, мультиязычность, декоративные анимации — всё это отдельные итерации позже.

**Текущий статус.** Итерация 1 «скелет с реальными текстами» полностью собрана и проверена в браузере: все секции ТЗ, адаптив, форма, лайтбокс, аккордеон, SEO-слой. На сайте стоят плейсхолдеры личных данных (см. раздел 11) — их заполняет владелец.

## 3. Стек и архитектурные решения

**Стек:** статические HTML5 + CSS + ванильный JS, без фреймворков и сборщиков (решение раздела 2 ТЗ).

Почему так, а не React/Tilda/конструктор:

- **Скорость.** Нет JS-бандла, нет hydration — PageSpeed мобильный 90+ достигается «из коробки». Лидер рынка («Молочные феи», milkyfairies.ru) сделал сайт JS-одностраничником и невидим для поисковиков — наш статический сайт выигрывает SEO бесплатно (вывод исследования).
- **Цена.** GitHub Pages — 0 ₽/мес; свой домен — от ~200 ₽/год. Российский хостинг как альтернатива — 40–300 ₽/мес.
- **Редактируемость.** Тексты и цены лежат прямо в `index.html` — правится блок за блоком без программиста.
- **Форма без бэкенда.** Заявка уходит напрямую в Telegram-бота через открытый API — сервер не нужен.

**Архитектура страницы:** один `index.html`, все секции идут по порядку воронки; стили — единый `css/style.css` на CSS-переменных (смена палитры = правка 6 строк в `:root`); скрипт — один `js/main.js` (~170 строк, три независимых модуля).

## 5. Поблочное устройство страницы

Все блоки реализуют раздел 4 ТЗ; тексты взяты из ТЗ дословно.

### 5.1 Шапка (`header`)
- Слева: `[Имя Фамилия]` + подпись «врач-педиатр, консультант по ГВ».
- Справа: телефон (ссылка `tel:`), круглые иконки WhatsApp и Telegram, кнопка «Записаться» (на мобильном скрыта — её роль играет плавающая кнопка; это исправило горизонтальную прокрутку на 320 px).
- Якорное меню: Обо мне · Услуги и цены · Как проходит · Отзывы · Вопросы (видно с 768 px).
- Шапка «липкая» (`position: sticky`) с полупрозрачным фоном и блюром; секции имеют `scroll-margin-top: 72px`, чтобы заголовки не прятались под шапку при переходе по якорям.

### 5.2 Первый экран — hero
- H1 по ТЗ: «Консультант по грудному вскармливанию в Гатчине, Ломоносове и Санкт-Петербурге» (единственный H1 на странице).
- Подзаголовок, 3 бейджа доверия («пилюли»), 2 кнопки: «Записаться на консультацию» (скролл к форме) и «Написать в Telegram».
- Справа — фото (сейчас SVG-заглушка с подписью, что заменить). На мобильном фото уходит под текст.

### 5.3 «Я сама мама»
- Заголовок + 3 абзаца истории (адаптация поста-знакомства из `Посты_ГВ_первые_5.docx`, плейсхолдеры в скобках).
- 3 карточки-факта: годы в педиатрии, часы обучения по лактации, годы собственного опыта ГВ. На десктопе — колонка справа, на мобильном — ряд из трёх.

### 5.4 Дипломы и сертификаты
- Сетка 2×2 на мобильном → 4 в ряд на десктопе.
- Клик по карточке открывает **лайтбокс** (полноэкранный просмотр, закрытие по ×, клику по фону или Esc).
- Сейчас стоят SVG-заглушки с названиями документов; замена = положить WebP-файл и поменять `src` (подписи — в `figcaption`).

### 5.5 Услуги и цены
- Таблица из 5 строк ТЗ (онлайн 60 мин 3000–3500 ₽; выезды Гатчина/Коммунар/Тайцы 3000 ₽, Ломоносов/Лебяжье/Б. Ижора 3500 ₽, СПб 4000 ₽; срочный выезд +500 ₽).
- На мобильном (`< 768 px`) таблица перестраивается в карточки: заголовки колонок печатаются над значениями через `td::before { content: attr(data-label) }`.
- Под таблицей — приписка «Если нужна не консультация, а врач — честно скажу и помогу найти».

### 5.6 Как проходит консультация
- 3 шага с круглыми номерами; на десктопе — три колонки.
- Плашка «Бесплатная линия: по средам 19:00–20:00» (пунктирная рамка, ссылка на чат — плейсхолдер).

### 5.7 Карта выезда (локальное SEO)
- Все 13 городов ТЗ отдельными «пилюлями» (список в HTML не сворачивается — важно для индексации): Гатчина, Коммунар, Тайцы, Сиверская, Вырица, Ломоносов, Лебяжье, Большая Ижора, Аннино, Петергоф, Стрельна, Красное Село, Санкт-Петербург.
- Формулировки «Онлайн-консультации — из любого города» и «Не нашли свой город? Напишите…».

### 5.8 Отзывы
- 3 карточки-заглушки с форматом подписи из ТЗ («Мария, мама Мирона, 2 месяца»). Добавление реального отзыва = скопировать `<blockquote class="review">…</blockquote>` и поменять текст. CMS не нужна.

### 5.9 FAQ
- 6 вопросов ТЗ в аккордеоне на нативном `<details>/<summary>` (работает даже с выключенным JS), стрелка +/− на чистом CSS.

### 5.10 Форма записи
- Поля: Имя*, телефон или @Telegram*, способ связи (select), ситуация (необязательно), чекбокс согласия с политикой* (по умолчанию не отмечен — требование ТЗ и 152-ФЗ).
- Скрытое honeypot-поле «Компания» — боты его заполняют, люди нет; заполненное = заявка молча отбрасывается.
- После отправки: статус-строка «Спасибо! Отвечу в течение часа…» либо честная подсказка «Форма ещё не подключена — напишите напрямую» (если бот не настроен).
- Дублирующие крупные кнопки Telegram/WhatsApp под формой (по ТЗ мессенджеры конвертят лучше).

### 5.11 Футер
- Имя, «Самозанятая · ИНН [плейсхолдер]», ссылки ВК / Telegram / Профи.ру, политика, © 2026.

### 5.12 Плавающая кнопка
- На экранах < 768 px внизу экрана закреплена кнопка «Записаться» (высота 52 px + учёт `safe-area-inset` для iPhone); на десктопе скрыта. Чтобы кнопка не перекрывала контент, у `body` на мобильных добавлен нижний отступ 76 px.

## 6. Дизайн-система

### Палитра (розово-бежево-молочная; изменена 11.11.2026 по запросу владельца)

Исходное ТЗ требовало «тёплую спокойную палитру, без аптечного голубого и кислотного розового» — поэтому розовый взят пыльный, приглушённый. Все цвета — CSS-переменные в `:root` (`css/style.css`); переопределение сайта = правка этого блока.

| Переменная | HEX | Роль |
|---|---|---|
| `--bg` | `#fdfaf4` | Молочно-белый фон страницы |
| `--bg-alt` | `#f6ece6` | Бежево-розовые чередующиеся секции |
| `--card` | `#ffffff` | Фон карточек, таблицы, формы |
| `--accent` | `#b56e7b` | Пыльная роза: кнопки, номера шагов, иконки |
| `--accent-dark` | `#9d5563` | Тёмная роза: ссылки, hover, подписи отзывов |
| `--accent-light` | `#f6e3e7` | Светло-розовый: бейджи, шапка таблицы, CTA-градиент |
| `--beige` | `#e9dbc8` | Тёплый беж (резерв/детали) |
| `--text` | `#3b3733` | Основной тёмно-серый текст |
| `--text-muted` | `#7d7069` | Второстепенный текст |
| `--border` | `#e8d9d3` | Розово-бежевые рамки карточек |

Тот же набор зашит в SVG-заглушки и favicon (после замены на фото палитра в них не нужна).

### Типографика
- Шрифтовой стек: `Inter, -apple-system, "Segoe UI", system-ui, Roboto…` — системные шрифты, ничего не грузится по сети (требование ТЗ «шрифты локально» + скорость).
- Базовый размер 16 px (минимум по ТЗ), H1 — 1.65rem на мобильном → 2.5rem на десктопе.

### Кнопки и интерактив
- Минимальная высота 48 px (по ТЗ), скругление 12 px, состояния hover с затемнением акцента.
- Видимые кольца фокуса `:focus-visible` (3 px пыльной розой) — и красиво, и доступно.

### Сетки и брейкпоинты (mobile-first, по ТЗ)
| Брейкпоинт | Что меняется |
|---|---|
| база (320–767) | Одна колонка; меню скрыто; таблица цен → карточки; плавающая кнопка |
| `≥ 768 px` | Появляется якорное меню; hero в 2 колонки; шаги и отзывы — 3 в ряд; дипломы — 4 в ряд |
| `≥ 1200 px` | Крупнее H1 и фото, контейнер до 1160 px |

## 7. JavaScript

Один файл `js/main.js`, три независимых модуля (падение одного не ломает остальные). Подключается с `defer`.

### 7.1 Конфигурация (верх файла)
```js
const CONFIG = {
  telegramBotToken: '', // токен бота от @BotFather
  telegramChatId: '',   // ваш chat_id (@userinfobot)
  metricaId: '',        // номер счётчика Яндекс Метрики
  telegramLink: 'https://t.me/username' // фолбэк, пока бот не настроен
};
```
Всё подключение формы и аналитики = заполнение четырёх строк.

### 7.2 Форма записи → Telegram
- `submit` перехватывается; honeypот-проверка; встроенная HTML5-валидация (обязательные поля, чекбокс).
- Собирается сообщение: «Новая заявка с сайта» + имя, контакт, способ связи, ситуация.
- `POST https://api.telegram.org/bot<токен>/sendMessage` (JSON, `parse_mode: HTML`).
- Таймаут 10 секунд (AbortController): на висящей сети человек не ждёт вечно.
- Успех → статус «Спасибо! Отвечу в течение часа…»; любая ошибка → подсказка со ссылкой-фолбэком. Кнопка на время запроса блокируется («Отправляю…»).

### 7.3 Лайтбокс
- Клик/Enter по `.diploma-item` открывает оверлей с картинкой и подписью; закрытие — ×, клик по фону, Esc. Скролл страницы блокируется на время просмотра.

### 7.4 Яндекс Метрика
- Если `CONFIG.metricaId` заполнен — динамически подгружается тег Метрики с вебвизором.
- Цели: `form_submit` (успешная отправка), `messenger_click` (клик по кнопкам мессенджеров). Идентификаторы целей нужно создать в интерфейсе Метрики с такими же именами.

FAQ-аккордеон — чистый HTML (`<details>`), JS не требует.

## 8. SEO-слой

- **Мета-теги** — дословно из раздела 6 ТЗ:
  - Title: «Консультант по грудному вскармливанию Гатчина, Ломоносов, СПб — врач-педиатр»
  - Description: «Помощь кормящим мамам онлайн и с выездом на дом… Запись в Telegram и WhatsApp»
  - Плюс Open Graph (заголовок/описание/URL для соцсетей и мессенджеров).
- **Один H1** на странице; секции — H2.
- **Микроразметка Schema.org** (JSON-LD, один блок `@graph`): `Person` (специалист), `LocalBusiness` (areaServed — все 12 городов, priceRange 3000–4000 ₽, часы 8:00–21:00), `FAQPage` (6 вопросов-ответов). Валидность JSON проверена.
- **robots.txt** — индексация разрешена, `Sitemap: https://ivanova-gv.ru/sitemap.xml` (домен-плейсхолдер, заменить).
- **sitemap.xml** — главная (priority 1.0) + политика (0.3).
- **Тексты** содержат целевые запросы ТЗ естественно: «консультант по грудному вскармливанию Гатчина/Ломоносов/Санкт-Петербург», «консультация по ГВ онлайн», города выезда перечислены списком.
- После публикации: добавить сайт в Яндекс Вебмастер и Bing Webmaster, отправить sitemap, создать карточку Яндекс Бизнеса (всё — в README).

## 9. Доступность

- Семантические теги: `header/nav/main/section/figure/blockquote/footer`, таблица с `scope="col"`.
- Форма: явные `<label for>`, обязательность отмечена звёздочкой + `aria-hidden`, статус отправки — `role="status" aria-live="polite"` (скринридер озвучит результат).
- Иконки-ссылки имеют `aria-label`; декоративные SVG — `aria-hidden`.
- Клавиатура: карточки дипломов — `role="button"` с `tabindex`, Enter/Space открывают лайтбокс; Esc закрывает; видимые кольца фокуса.
- `prefers-reduced-motion`: отключает плавный скролл и все переходы.

## 10. Производительность

- Ноль внешних запросов, кроме отправки формы: шрифты системные, стили и скрипт локальные (~13 КБ CSS + ~7 КБ JS без сжатия).
- Изображения: `loading="lazy"` на дипломах, `fetchpriority="high"` на фото hero, явные `width/height` (нет «прыжков» вёрстки).
- Итог: даже на медленном 3G страница рендерится за доли секунды; цель «PageSpeed мобильный ≥ 90» достигается без оптимизаций. После замены заглушек на фото — конвертировать в WebP и сохранить размеры в атрибутах.
- Проверено фактически: отсутствие горизонтальной прокрутки на 320 px, работа формы/аккордеона/лайтбокса, валидность HTML и JSON-LD.

## 13. Подключение Telegram-бота и Яндекс Метрики

### Telegram-бот (5 минут)
1. В Telegram: **@BotFather → /newbot** → имя и username бота → скопировать токен (`123456:ABC-DEF…`).
2. Узнать свой chat_id: написать **@userinfobot** (или любому боту, затем открыть `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и взять `chat.id`).
3. Открыть `js/main.js`, заполнить `telegramBotToken` и `telegramChatId`. Готово: заявки с сайта прилетают в личный чат.
4. Проверка: отправить тестовую заявку с сайта.

### Яндекс Метрика (5 минут)
1. [metrika.yandex.ru](https://metrika.yandex.ru) → Добавить счётчик → URL сайта → включить «Вебвизор».
2. Номер счётчика вписать в `CONFIG.metricaId` в `js/main.js`.
3. В настройках счётчика создать цели с идентификаторами `form_submit` и `messenger_click` (тип «JavaScript-событие»).
